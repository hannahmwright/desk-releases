# Desk

Desk is a Mac app for mail and calendar (Gmail, Google Workspace and iCloud), made by Verve Technologies LLC.

**Download:** get the latest `Desk-x.y.z.dmg` from [Releases](https://github.com/hannahmwright/desk-releases/releases/latest), open it and drag Desk to Applications. Desk updates itself after that (Desk → Check for Updates…).

Requires macOS 26 or later. [What Desk does](https://www.vervetechgroup.com/desk) · [Privacy Policy](https://www.vervetechgroup.com/desk/privacy)

This repository holds only signed, notarized builds and the update feed (`appcast.xml`).
